## Products that cannot be listed (loopback, custom URL scheme, or local bounce)

These products deliver the OAuth authorization code to a loopback port or custom URL scheme on the user's machine. That proves only "an app on this computer", so they cannot be verified by origin in the directory.

| Product                         | Redirect pattern                                                                                    | Why it cannot be listed                                                                                                                                                                                                                                                                                       | Vendor evidence (verified 2026-11-20)                                                                                                                  |
| ------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Claude Code (CLI)               | `http://localhost:<port>/callback`, `http://127.0.0.1:<port>/callback`                              | Loopback redirect on ephemeral or configured local port                                                                                                                                                                                                                                                       | <https://claude.ai/oauth/claude-code-client-metadata> and <https://claude.com/docs/connectors/building/authentication>                                 |
| Cursor Desktop App (local flow) | `http://localhost:8787/callback` (default), `cursor://anysphere.cursor-mcp/oauth/callback` (legacy) | Loopback redirect and custom URL scheme (`https://www.cursor.com` is listed above only for Cursor Web / Cloud Agents and web-bounced sign-ins)                                                                                                                                                                | <https://cursor.com/docs/mcp> and <https://forum.cursor.com/t/oauth-redirect-uri-changed-from-cursor-to-http-localhost-for-streamable-http-mcp/165019> |
| VS Code / GitHub Copilot        | `http://127.0.0.1:33418` and `https://vscode.dev/redirect`                                          | Desktop uses loopback (`127.0.0.1:33418`); `https://vscode.dev/redirect` is a generic bridge that relays callbacks back to local `vscode://` / `vscode-insiders://` handlers as well as web sessions, so verifying `vscode.dev` would misrepresent a local editor/extension as a Microsoft-hosted cloud agent | <https://code.visualstudio.com/api/extension-guides/ai/mcp>                                                                                            |
| Zed                             | `http://127.0.0.1:<port>/callback`                                                                  | Loopback redirect declared in Zed's Client ID Metadata Document (`["http://127.0.0.1/callback"]`)                                                                                                                                                                                                             | <https://zed.dev/oauth/client-metadata.json>                                                                                                           |
| Gemini CLI                      | `http://localhost:<port>/oauth/callback`                                                            | Loopback redirect on random or configured local port                                                                                                                                                                                                                                                          | <https://geminicli.com/docs/tools/mcp-server/>                                                                                                         |
| OpenAI Codex CLI                | `http://127.0.0.1:<port>/callback/<callback_id>`, `http://localhost:<port>/callback/<callback_id>`  | Loopback redirect on local port                                                                                                                                                                                                                                                                               | <https://github.com/openai/codex/issues/30460>                                                                                                         |
