Get started

Running in minutes.

On your Mac

Download it, open it, connect Chrome and sign in to an agent. Your phone pairs in one scan.

Download for Mac

On a server for your team

Run the Host, its database and a Linux runner with Docker Compose.

$ git clone https://github.com/steerlabs/opensteer
$ cd opensteer/deploy/self-host
$ docker compose up -d

From source

Fork it, change anything, ship your own build.

$ pnpm install --frozen-lockfile
$ pnpm setup:local
$ pnpm dev
