# Opensteer Passwords failure inventory

Each entry is a way the part can fail. **Defence** names the behaviour that prevents it, and
**Test** names the XCTest that proves it. "Error" means the operation throws.
It never repairs, falls back or carries on.

Sections 1–8 are `PasswordsCore`; sections 9–18 are the broker app
(`PasswordsBrokerKit`, `PasswordsBroker`), the import worker, packaging,
grants and the authentication policy. Broker tests run the real IPC server on
a temporary socket with the development peer rule, a software owner key store
and scripted authentication, so none of them can show a Touch ID, password or
Keychain prompt.
